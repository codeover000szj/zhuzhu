# 微信个人收款码（人工核验）

当前商城在订单详情中展示 `vue3/public/payment/wechat-personal-qr.jpg`。该图片是用户提供的个人静态收款码；用户选择后，订单只记录 `WECHAT_QR` 支付方式并保持待支付。扫码和用户点击“我已转账”均不会把订单标记为已支付。

## 当前接口

- `POST /shop/order/{id}/payment/wechat-qr`：用户选择个人收款码，订单仍待支付。
- `GET /shop/order/{id}/payment/status`：查询服务端保存的订单状态。
- `POST /shop/order/{id}/payment/wechat-qr/confirm`：管理员核对微信收款账单后人工确认。接口检查管理员角色，并且只允许将待支付的微信码订单更新为已支付。

个人静态码没有订单号、金额和到账状态的服务器回调；当前人工确认接口是教学项目的收款核对流程，不是微信支付商户 API。服务端日志会记录人工确认的订单号、金额、管理员 ID 和时间。

## 后续接真实支付

真实自动确认应接入微信支付商户 API：服务端创建支付单并返回平台支付参数，微信支付平台向独立的 HTTPS 通知接口发送结果，服务端验证平台签名、商户号、订单号、金额、币种和交易状态，再以幂等方式更新订单。前端“我已转账”不得作为支付凭证。

当前订单详情、支付状态查询和管理员核验接口可作为应用内边界；真正的微信商户下单、签名验签、异步通知和查单接口尚未实现。接入前需要商户号、API v3 密钥、商户 API 证书/私钥及可公网访问的 HTTPS 回调地址。请将密钥保存在本机私密配置或部署环境变量中，不要提交到源码、归档或聊天中。接入正式支付后，应关闭本地演示支付。
